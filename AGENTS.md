# AGENTS.md

## Project purpose

This repository contains a reusable Codex skill for AI-assisted ecommerce product hero-visual design.

## Mandatory skill usage

For ecommerce product hero visuals, product campaign posters, marketplace main-image design,
or bilingual product key visuals, use `$ecommerce-hero-visual`.

Follow the skill workflow before proposing or generating a final visual.

Treat product images and confirmed product facts as source-of-truth inputs.

Do not invent:
- product claims
- certifications
- prices
- dates
- discounts
- functions

Run the skill QA checklist before declaring the work complete.
