# Workflow and Production Gates

## Gate 1 — Evidence Before Generation

Complete the brief, evidence classification, communication hierarchy, and visual direction before producing a final visual.

Do not generate a final product visual without a usable product reference unless the user explicitly requests a non-fidelity concept mockup. Label any such mockup clearly as conceptual.

## Gate 2 — Preserve Product Identity

Keep visible silhouette, proportions, color, material appearance, logo placement, and structural details aligned with the approved product source. Do not add plausible-looking features that are not visible or confirmed.

## Gate 3 — Preserve Claim Meaning

Marketing expression may improve clarity or tone but must not strengthen, broaden, or certify the underlying fact.

Allowed example:

- confirmed: “12 小时保温保冷”
- expression: “冷热续航最长 12 小时”

Not allowed:

- “全天恒温”
- “医用级认证”
- “100% 防漏”

unless the corresponding claim is explicitly confirmed.

## Gate 4 — Separate Image and Type

Prefer this sequence:

1. text-free base;
2. product-fidelity and negative-space check;
3. typography using exact confirmed copy;
4. final visual QA.

If an image model renders accidental text, remove or regenerate it before typography.

## Gate 5 — Commercial Clarity

Prioritize fast product recognition, concise hierarchy, readable type, and a clear action over decorative complexity. Props and scenes must support the strategy without obscuring or altering the product.

## Gate 6 — QA, Revision, and Stop Condition

Run the quality checklist on every produced stage. For each blocking or high-severity issue:

1. record the issue and affected area;
2. revise the asset, prompt, layout, or copy plan;
3. re-check the failed criterion.

Stop only when no blocking or high-severity issue remains, or when missing verified input prevents further correction. In the latter case, state the blocker and do not describe the output as final.
